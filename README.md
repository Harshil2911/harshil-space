# Harshil Raval — Personal Portfolio

**Retro-Futurist Dark Tech** personal portfolio for Harshil Raval — Serial Entrepreneur & AI Automation Founder.

Built with Next.js 14 · Tailwind CSS · React Three Fiber · GSAP · Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS + Custom CSS Properties
- **3D**: React Three Fiber + Three.js
- **Animations**: GSAP (loader) + CSS IntersectionObserver (scroll)
- **Forms**: Formspree
- **Deployment**: Vercel
